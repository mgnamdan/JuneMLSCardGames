# Visual Card Games

This folder contains the PyQt6 version of the Blackjack and Go Fish application.

Install the interface dependency:

```powershell
python -m pip install -r requirements.txt
```

Run the application:

```powershell
python main.py
```

The interface uses styled placeholders for cards, so no external image assets are required.

Blackjack begins each session with $10.00 USD in chips. After choosing to stay,
use the wager controls to bet up to $2.00 before the remaining hands are resolved.
